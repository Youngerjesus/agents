# Context Loading

## Usage
`/context [task description or keywords]`

## Example
`/context fix the login bug in the auth service`
`/context add a new field to the user profile`

## Instructions

1.  **Phase 1: Discovery (Search Agent)**
    *   **Invoke**: Call the **Search Agent** defined in `.claude/agents/search_agent.md`.
    *   **Input**: "Analyze the codebase for the following task: **$ARGUMENTS**. **CRITICAL**: Read `work_queue/worklog_list.json` to understand the history and context of this task before identifying files."
    *   **Goal**: The Search Agent must generate a "Blueprint" list of files marked as `@target` (for editing) and `@ref` (for reference).

2.  **Phase 2: Assembly (Context Agent)**
    *   **Invoke**: Call the **Context Agent** defined in `.claude/agents/context_agent.md`.
    *   **Input**: Pass the **Original Task** ($ARGUMENTS) AND the **Blueprint** generated by the Search Agent in Phase 1.
    *   **Goal**: The Context Agent must excute the `ast_compiler.py` script to compile these files into a single component context XML file.

3.  **Phase 3: Verification**
    *   **Action**: Confirm that the XML file has been created in the `contexts/` directory.
    *   **Feedback**: Report back to the user with the path of the generated context file and a summary of the architectural note.
